# DramaThon Plus

DramaThon Plus is a modern Android application designed for a premium drama viewing experience. It features a sleek interface, advanced video playback capabilities, and intuitive navigation.

## Features

- **High-Quality Video Playback**: Supports fullscreen immersive mode, auto-play for next episodes, and manual episode selection shortcut.
- **Progress Tracking**: Automatically marks watched episodes with visual indicators (eye icon and color coding).
- **Adaptive UI**: Clean, responsive design with a dark theme, optimized for both browsing and viewing.
- **Search & Filter**: Easily find your favorite dramas through search and categorized tabs (Latest, Trending, For You, etc.).
- **Media Controls**: Integrated player controls including play/pause, next/previous, seekbar, and episode list shortcut.

## Technologies Used

- **Kotlin**: Primary programming language.
- **Jetpack Compose**: For a modern, declarative UI.
- **Media3 (ExoPlayer)**: For high-performance video streaming and playback.
- **Coil**: For efficient image loading and caching.
- **Coroutines & Flow**: For reactive and asynchronous programming.
- **Material 3**: For state-of-the-art UI components and theming.

## Development

This project is structured with sustainability in mind, separating UI components (`MainScreen`, `VideoPlayerView`, `DramaGridView`, `DramaDetailView`) from core logic for easier debugging and maintenance.
